🗜️ Page 05 - RLE + Huffman (VLC)

Fonction : Encode les vecteurs zigzag en bitstream compressé.
• RLE : Transforme en paires (run, level) où run = zéros consécutifs, level = valeur non-nulle
• VLC : Code chaque paire avec un code Huffman de longueur variable
Entrée : Fichier JSON des vecteurs zigzag (sortie Page 04)
Sortie : Fichier JSON contenant les bitstreams de chaque bloc
Codage conforme MPEG-2 (ISO 13818-2 §7.2, annexe B) :
• DC : différence avec le DC précédent de la même composante (Y, Cb, Cr ont chacune leur prédicteur, remis à 128 au début de chaque slice) ; taille codée par la table B.12 (luminance) ou B.13 (chrominance), suivie de la valeur.
• AC : paires (run, level) codées par la table B.14 complète, suivies du bit de signe ; paire absente de la table → ESCAPE (000001) + run sur 6 bits + level sur 12 bits. Chaque bloc se termine par EOB (10).
Vecteur [64] → DC (DPCM) → RLE (run,level) → VLC Huffman → Bitstream
