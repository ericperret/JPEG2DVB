🔀 Page 04 - Scan Zigzag

Fonction : Réorganise les 64 coefficients du bloc 8×8 en parcours diagonal (zigzag).
Ce parcours regroupe les zéros (hautes fréquences) à la fin du vecteur, optimisant le RLE.
Entrée : Fichier JSON des coefficients quantifiés (sortie Page 03)
Sortie : Fichier JSON des vecteurs 64 valeurs en ordre zigzag
Précisions MPEG-2 (ISO 13818-2 §7.3) :
• Le zigzag montré ici est le balayage 0 (alternate_scan = 0), adapté aux images progressives. MPEG-2 prévoit un balayage alterné (alternate_scan = 1), plus vertical, pour la vidéo entrelacée où l'énergie se concentre autrement.
• Ordre de la chaîne : quantification puis zigzag, comme la norme (le décodeur fait l'inverse : scan inverse → quantification inverse → IDCT). La quantification étant coefficient par coefficient et le zigzag une simple permutation, l'ordre inverse donnerait le même résultat si la matrice reste indexée en ordre naturel.
