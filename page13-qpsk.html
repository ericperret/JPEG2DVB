📡 Page 13 - Mapping QPSK

Fonction : Modulation QPSK (Quadrature Phase Shift Keying) selon DVB-S EN 300 421.
Principe : 2 bits → 1 symbole complexe (I, Q) sur la constellation.
Mapping Gray : Symboles adjacents diffèrent d'1 seul bit → minimise erreurs.
Entrée : Bits codés — Sortie : Symboles I/Q normalisés
TS → PRBS → RS → Entrelacement → Convolutif → QPSK → SRRC
