📦 Page 06 - Assemblage Elementary Stream

Fonction : Assemble les bitstreams VLC en un Elementary Stream MPEG-2 Video complet.
Structure : Sequence Header → GOP Header → Picture Header → Slices (1 par ligne de MB)
Entrée : Fichier JSON des bitstreams VLC (sortie Page 05)
Sortie : Fichier binaire ES (.es) + JSON avec métadonnées
Paramètres de quantification dans le flux (ISO 13818-2 §6.2.2.1, §6.3.16) :
• La matrice intra choisie en page 03 est reprise : matrice MPEG-2 par défaut → load_intra_quantiser_matrix = 0 ; autre matrice → bit à 1 suivi des 64 valeurs en ordre zigzag dans le Sequence Header.
• Le quantiser_scale_code de la page 03 est écrit dans chaque slice. Le décodeur reconstruit donc exactement les coefficients que la page 03 a quantifiés : le flux est décodable par un lecteur MPEG-2 standard (ffmpeg, VLC).
