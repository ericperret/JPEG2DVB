📺 Page 08 - Empaquetage Transport Stream

Fonction : Découpe le flux PES en paquets Transport Stream de 188 octets.
Ajoute les tables PSI : PAT (Program Association Table) et PMT (Program Map Table).
Entrée : Fichier JSON du PES (sortie Page 07)
Sortie : Fichier .ts compatible lecteurs multimédia
Horloge de référence conforme ISO 13818-1 (§2.4.3.4, §2.4.3.5) :
• La PMT désigne le PID qui porte le PCR (Program Clock Reference) : ici la vidéo, PID 0x0101. Le PCR recale l'horloge 27 MHz du décodeur sur celle de l'émetteur ; sans lui, le PTS de la page 07 n'a pas de référence.
• Le PCR est écrit dans l'adaptation field du premier paquet vidéo : base 33 bits à 90 kHz + extension 9 bits (PCR = base × 300 + extension). PCR initial = 0, PTS = 63 000 : l'image s'affiche 0,7 s après.
• random_access_indicator = 1 : ce paquet est un point d'entrée (Sequence Header + image I). En diffusion réelle, le PCR est répété au moins toutes les 100 ms.
PES → PAT → PMT → Paquets 188 oct → TS

Structure du paquet TS (188 octets)

┌──────────────────────────────────────────────────────────────────────────────────────┐ │ HEADER (4 octets) │ ├───────────┬───────────┬───────────────────────────────────────────────────────────────┤ │ sync_byte │ TEI│PUSI│TP│ PID (13 bits) │ TSC │ AFC │ CC (4 bits) │ │ 0x47 │ 1 │ 1 │1 │ 0x0000=PAT, 0x0100=PMT... │ 2 │ 2 │ continuity cnt │ ├───────────┴───────────┴───────────────────────────────────────────────────────────────┤ │ ADAPTATION FIELD (optionnel, si AFC=10 ou 11) │ │ adaptation_field_length │ flags │ [stuffing bytes 0xFF] │ ├───────────────────────────────────────────────────────────────────────────────────────┤ │ PAYLOAD (max 184 octets) │ │ Pour PAT/PMT: pointer_field + table_section │ │ Pour Vidéo: données PES │ └──────────────────────────────────────────────────────────────────────────────────────┘ Légende: TEI = Transport Error Indicator TSC = Transport Scrambling Control PUSI = Payload Unit Start Indicator AFC = Adaptation Field Control TP = Transport Priority CC = Continuity Counter

Tables PSI

Table PID Table ID Contenu
PAT (Program Association Table) 0x0000 0x00 Liste des programmes → PID de leur PMT
PMT (Program Map Table) 0x0100 0x02 Liste des flux du programme → leurs PIDs
Null Packet 0x1FFF - Remplissage (padding)
