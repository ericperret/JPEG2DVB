📊 Page 03 - Quantification

Fonction : Division des coefficients DCT par une matrice de quantification.
Cette étape introduit la compression avec pertes : les hautes fréquences sont plus atténuées.
Entrée : Fichier JSON des coefficients DCT (sortie Page 02)
Sortie : Fichier JSON des coefficients quantifiés (entiers, beaucoup de zéros)
Quantification conforme MPEG-2 (ISO 13818-2 §7.4) :
• DC intra : diviseur fixe 8 (intra_dc_precision = 0, 8 bits) → valeur 0 à 255, indépendante de la matrice et de l'échelle ; codée ensuite en différence avec le bloc précédent (page 05).
• AC : QF = round(16·F / (W·quantiser_scale)), inverse exact de la reconstruction du décodeur F = (2·QF·W·quantiser_scale) / 32. Le facteur qualité est converti en quantiser_scale_code (1 à 31, quantiser_scale = 2 × code, table linéaire) ; la matrice W et ce code sont transmis à la page 06, qui les écrit dans le flux.
• Matrice JPEG ou plate : transmise comme matrice intra personnalisée (son premier terme, réservé au DC, vaut 8).
Coeffs DCT → ÷ Matrice Q → Arrondi → Coeffs quantifiés
