Conversion RGB → YCbCr (BT.601)

Standard ITU-R BT.601 (SD TV, PAL/NTSC): Y = 16 + 65.481×R + 128.553×G + 24.966×B [16-235] Luminance Cb = 128 - 37.797×R - 74.203×G + 112.000×B [16-240] Chrominance Bleue Cr = 128 + 112.000×R - 93.786×G - 18.214×B [16-240] Chrominance Rouge Où R, G, B sont normalisés [0-1] après correction gamma. Note: Les valeurs 16-235/16-240 laissent une marge "headroom/footroom" pour les dépassements analogiques (super-blanc, super-noir).
