📐 Page 02 - DCT 8×8 (Discrete Cosine Transform)

Fonction : Applique la Transformée en Cosinus Discrète 2D sur chaque bloc 8×8.
La DCT convertit les valeurs spatiales (pixels) en coefficients fréquentiels.
Entrée : Fichier JSON des macroblocs (sortie Page 01)
Sortie : Fichier JSON des coefficients DCT pour chaque bloc
DCT conforme MPEG-2 intra (ISO 13818-2 §7.5, annexe A) :
• Pas de centrage à −128 (c'est une convention JPEG) : les pixels 0 à 255 sont transformés tels quels, le DC vaut 8 × la moyenne du bloc (0 à 2040) et sera divisé par 8 en page 03.
• Coefficients rangés en ordre naturel F[v][u] : ligne = fréquence verticale, colonne = fréquence horizontale, comme le suppose le balayage zigzag de la page 04.
Macroblocs → Pixels 0-255 → DCT 2D → Coefficients
